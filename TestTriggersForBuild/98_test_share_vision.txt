//
//  켜는 법: 이 파일을 Triggers/ 폴더로 복사
//  끄는 법: Triggers/ 에서 제거
//
//  사용 스크립트 (AI → 해당 플레이어로 시야 공유):
//    "Turn ON Shared Vision of current player with Player 1"
//    "Turn ON Shared Vision of current player with Player 2"
//    "Turn ON Shared Vision of current player with Player 3"
//    "Turn ON Shared Vision of current player with Player 4"
//
//  주의: 위 스크립트 이름이 SCMDraft 드롭다운에 정확히 그대로 있는지
//        확인할 것. 표기가 다르면 적절히 교체.
//        ("of [SHARER] with [RECEIVER]" 패턴으로 추정)
//-----------------------------------------------------------------//

Trigger("Player 1", "Player 2", "Player 3", "Player 4"){
Conditions:
	Elapsed Time(At most, 1);
Actions:
	Run AI Script("+Vi4");
	Run AI Script("+Vi5");
	Run AI Script("+Vi6");
	Run AI Script("+Vi7");
}
