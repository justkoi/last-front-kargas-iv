============================================================
  KARGAS IV - Location 배치 가이드
  트리거 Import 전에 SCMDraft에서 만들어야 할 영역들
============================================================

[Location 만드는 법]
1. SCMDraft 좌측 툴바 -> Location 모드 (사각형 아이콘)
2. 맵에서 영역을 드래그해서 사각형 만들기
3. 더블클릭 -> 이름 입력
4. ⚠️ 이름은 트리거 파일과 정확히 일치해야 함 (대소문자/공백 포함)

============================================================
  작업 순서
============================================================

1. 위 필수 Location 다 만들기
2. SCMDraft -> Triggers (Ctrl+T)
3. File -> Import Text Triggers
4. KargasIV_Triggers.txt 선택
5. 에러 없으면 OK!

[자주 발생하는 에러]
- "Location not found" -> Location 이름 오타 확인
- "Unit not found" -> 유닛 이름이 영문으로 정확한지 확인
- "AI Script not found" -> 스크립트 이름 정확한지 확인

- 네 영웅 모두 행동불능 시 5분 후 미네랄 100을 소모해 소유자의 Command Center / Hatchery / Lair / Hive / Nexus에서 복귀
- 로크/세딘 영웅 본체는 별도 고유 능력과 능력치 변경 없이 기본 영웅 설정 사용

============================================================
  미션 진행 시스템 (Death Counter 사용)
============================================================

이 트리거는 "Death Counter"를 스위치 대신 사용합니다.
"Player 8"의 "Zergling" 카운터로 미션 단계를 추적:

  값 1 : 미션 1 진행중
  값 2 : 미션 1 진행 (AI 시작 후)
  값 3 : 미션 1 완료, 미션 2 시작 대기
  값 4 : 미션 2 진행중
  값 5 : 미션 2 완료, 미션 3 시작
  값 6 : 미션 3 진행중
  값 7 : 미션 3 완료, 미션 4 시작
  값 8 : 미션 4 진행중
  값 9 : 미션 4 완료, 미션 5 시작
  값 10: 미션 5 진행중 (보스전)

⚠️ 디버그 시 트리거 -> Set Deaths로 임의 변경 가능 (테스트 편함)
