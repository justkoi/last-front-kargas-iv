//  터보 트리거 (Hyper Trigger) × 4 - Player 8 소유
//
//  원리: Wait 액션 직전에 모든 트리거 조건을 재검사 → Wait(0) 다수로
//        초당 ~12회 트리거 평가 강제. 12 DC tick = 1초 공식 성립.
//
//  4개 배치 이유 (NEO 갭 곱연산):
//    NEO 사이클 = (Wait 개수 + 1) ^ (트리거 개수)
//    1개: 63 사이클 ≈ 5초마다 끊김 (사실상 무효)
//    4개: 63^4 ≈ 1575만 사이클 ≈ 15일 이상 무중단 → 어떤 게임 길이도 안전
//
//  Player 8 단독 소유: 다른 Wait를 사용하는 트리거가 P8에 없음을 확인.
