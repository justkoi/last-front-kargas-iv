//============================================================
//  KARGAS IV - Mission trigger notes
//  Required Locations: P1~P4 Start, P5 Base, P5 Scout, P5 Intruder,
//                      P1~P4 Hunt, Player Destination, P6 Base, P7 Base,
//                      Mission2 Gate, New Pass1, Raid1~3
//
//  Timer rule: 12 DC tick = 1 second
//    60s = 720, 90s = 1080, 3min = 2160, 4min = 2880
//
//  Player 8 DC roles
//    Terran Civilian      : zerg resource supply timer
//    Terran Marine        : P5 base defense cooldown
//    Terran Valkyrie      : mission phase flag (1=M1, 3=M2, 4=clear)
//    Terran Vulture       : mission2 elapsed timer
//    Terran Armory        : mission2 waiting-phase legacy flag
//    Protoss Probe        : mission1 scout rotation index
//    Protoss Zealot       : unused legacy counter
//    Terran Firebat       : P1 Hunt tracking timer
//    Terran Ghost         : P2 Hunt tracking timer
//    Terran Medic         : P3 Hunt tracking timer
//    Terran SCV           : P4 Hunt tracking timer
//    Terran Goliath       : scout overlord cycle timer
//    Terran Wraith        : mission1 late-wave cooldown
//    Terran Battlecruiser : overlord supply cycle timer
//    Terran Science Vessel: player alliance refresh timer
//    Terran Dropship      : mission1 late-wave variant index
//    Zerg Drone           : mission2 gate-open flag
//
//  Switch roles
//    Switch1 : defeat guard
//    Switch2 : resource raid sites revealed/spawned
//    Switch3 : Raid1 cleared
//    Switch4 : Raid2 cleared
//    Switch5 : Raid3 cleared
//    Switch6 : mission2 P7 airstrike one-time flag
//    Switch7 : mission1 multi scan revealers created
//    Switch8 : mission1 multi scan revealers removed
//
//  Note: avoid Order("...", "Men", ...) for broad combat orders.
//============================================================
