# 병참감찰관 세딘

## 기본 정보

| 항목 | 내용 |
|---|---|
| 이름 | 세딘 |
| 직책 | 병참감찰관 |
| 기반 유닛 | Alan Schezar (Goliath) |
| 인물 색상 | `<1F>` Turquoise |
| 전장 역할 | 기갑 전력과 보급 상태를 함께 관리하는 중장갑 지원 지휘관 |
| 합류 시점 | 미션 1 지휘 정신체 파괴 후 |
| 합류 위치 | `HeroDJoin` |
| 고유 능력 | 현재 미적용 |

## 인물 개요

세딘은 전투를 탄약, 이동 거리, 수리 시간과 남은 전력의 문제로 바라보는 병참 책임자다. 숫자만 따지는 관료가 아니라, 보급 계획이 무너지면 자신이 직접 골리앗 조종석에 올라 현장을 수습한다. 승리 가능성을 높이는 가장 확실한 방법은 필요한 병력이 필요한 순간에 멈추지 않게 만드는 것이라고 믿는다.

지휘 정신체가 발생시킨 방해 신호는 세딘이 관리하던 잔존 기갑대의 교신과 집결을 끊어 놓았다. 세딘은 흩어진 전력을 작은 단위로 유지하면서 통신 복구를 기다렸고, 선봉대가 지휘 정신체를 파괴하자 현 위치에서 기갑대를 다시 묶어 작전 지휘망에 합류한다.

## 성격과 판단 기준

- 침착하고 격식을 지키지만 불필요하게 완곡하지 않다.
- 전투의 비용을 계산하되 사람을 단순한 소모품으로 취급하지 않는다.
- 준비 없는 용맹보다 다음 전투까지 이어지는 승리를 높게 평가한다.
- 부족한 상황에서는 가진 전력을 숨기지 않고 우선순위를 분명히 제시한다.
- 현장의 즉흥 판단을 인정하지만, 같은 손실이 반복되는 것은 용납하지 않는다.
- 책임을 다른 부서에 돌리기보다 자신이 통제할 수 있는 대안을 먼저 찾는다.

## 다른 인물과의 관계 방향

### 발렌

발렌이 요구하는 공격 시점과 전선 확장 속도를 보급 관점에서 검토한다. 불가능한 요구에는 분명히 반대하지만, 작전 가치가 충분하면 예비 물자까지 동원해 실행 가능한 형태로 바꾼다.

### 엘리아

엘리아의 공세 예측을 보급 우선순위와 수리 계획으로 번역한다. 두 사람 모두 구체적인 근거를 중시하기 때문에 의견 충돌이 생겨도 감정보다 자료와 결과로 정리하는 편이다.

### 로크

로크의 기동력이 전선을 살리는 경우를 인정하면서도 장비 손실과 무리한 이동을 자주 지적한다. 로크가 새로운 길을 열면 세딘은 그 길이 다음 병력도 통과할 수 있는 전선이 되도록 뒤를 정리한다.

## 말투 지침

- 존댓말을 기본으로 사용한다.
- 상황, 손실 또는 준비 상태를 짧게 밝힌 뒤 실행안을 제시한다.
- 감탄이나 위협보다 확인, 재편, 유지, 배치 같은 실무 표현을 선호한다.
- 지나치게 차갑거나 사람을 숫자로만 보는 인상은 피한다.
- 대사에서는 `유닛`, `스위치`, `DC`, `Location` 같은 편집기 용어를 사용하지 않는다.
- `보급망`, `잔존 기갑대`, `수리`, `예비 전력`, `집결`, `재편`처럼 세계 안에서 이해되는 말을 사용한다.

## 현재 구현된 대사

합류 대사:

```text
<1F>병참감찰관 세딘: <04>방해 신호가 사라졌습니다. 잔존 기갑대를 수습해 현 위치에서 합류하겠습니다.
```

소유자 합류 안내:

```text
<07>[영웅 합류] <1F>세딘<04>이 귀관의 지휘에 합류했습니다.
```

행동불능 안내:

```text
<06>[행동 불능] <1F>세딘<04>이 후송되었습니다. 5분 후 미네랄 100을 소모해 배속된 지휘관의 본진에서 복귀합니다.
```

복귀 안내:

```text
<07>[전선 복귀] <1F>세딘<04>이 배속된 지휘관의 본진에서 복귀했습니다. <1F>(미네랄 -100)
```

## 현재 게임 구현

- 영웅 시스템 초기화가 끝난 뒤 `P5 Cerebrate`의 지휘 정신체 부재를 별도로 감지해 합류 요청을 기록한다.
- 이 감지는 난이도 선택 여부와 미션 진행 단계에 의존하지 않는다. 실제 배속은 로크 배속과 로크의 168틱 합류 연출이 끝난 뒤 시작한다.
- 세딘 소유자는 Player 8의 `Zerg Queen's Nest` DC 하나로 기록한다. `0`은 미배속, `1~4`는 각각 P1~P4이며 별도의 배속 완료 스위치는 사용하지 않는다.
- 발렌, 엘리아, 로크를 모두 배속받지 않은 생존 플레이어를 우선한다.
- 합류 직전 `HeroDJoin`의 모든 플레이어/중립 `Men`과 `Buildings`를 `HeroDJoinExit`으로 이동시킨다.
- 이동과 같은 트리거에서 세딘을 `HeroDJoin`에 생성한다.
- 생성 보호나 주변 적 제거는 적용하지 않는다.
- 행동불능 후 3600틱(5분)이 지나고 소유자가 미네랄 100과 본진 건물을 보유하면 복귀한다.
- HP, 공격력, 방어력, 업그레이드와 별도 고유 능력은 아직 변경하지 않는다.

## 향후 확장 시 유지할 핵심

- 세딘의 정체성은 단순한 자원 지급보다 전력을 끊기지 않게 유지하고 재편하는 데 있다.
- 향후 능력을 추가하더라도 전투를 대신 수행하는 자동 효과보다는 손실 복구, 보급 판단, 중장갑 지원과 연결하는 편이 어울린다.
- 지휘 정신체가 보급망과 집결을 끊었다는 경험은 이후 통신 장애나 장기전에 관한 대사의 근거로 사용할 수 있다.
