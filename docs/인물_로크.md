# 특수작전장교 로크

## 기본 정보

| 항목 | 내용 |
|---|---|
| 이름 | 로크 |
| 직책 | 특수작전장교 |
| 기반 유닛 | Jim Raynor (Vulture) |
| 인물 색상 | `<1A>` Cyan |
| 전장 역할 | 고속 기동과 현장 판단을 담당하는 기동전 지휘관 |
| 합류 시점 | 미션 1 전방 정신체 파괴 후 |
| 합류 위치 | `HeroCJoin` |
| 고유 능력 | 현재 미적용 |

## 인물 개요

로크는 명령을 기다리기보다 현장의 빈틈을 먼저 찾아 움직이는 기동전 지휘관이다. 무모하게 돌진하는 인물은 아니지만, 완벽한 정보를 기다리다가 기회를 놓치는 것을 더 큰 실수로 여긴다. 빠르게 진입하고 짧게 타격한 뒤 전력이 묶이기 전에 빠져나오는 전투 방식을 선호한다.

전방 정신체의 교란망이 형성되었을 때 로크의 기동대는 본대와 분리되었다. 장거리 교신과 위치 확인이 불가능해진 상황에서도 부대를 흩어 버리지 않고 정신체 주변의 사각에 숨어 기회를 기다렸다. 선봉대가 전방 정신체를 파괴해 교란망이 무너지자, 로크는 잔존 병력을 정리하고 현장에서 작전 지휘망에 합류한다.

## 성격과 판단 기준

- 결론이 빠르고 말이 짧다.
- 위험을 피하지는 않지만 퇴로 없이 싸우는 것은 싫어한다.
- 계급보다 실제 전황과 실행 가능한 선택지를 중시한다.
- 칭찬이나 감정을 길게 표현하지 않고 다음 행동으로 신뢰를 보인다.
- 자신의 판단이 틀렸다면 변명하지 않고 즉시 경로를 바꾼다.
- 고립과 교신 두절을 겪었기 때문에 병력이 이유 없이 방치되는 상황에 민감하다.

## 다른 인물과의 관계 방향

### 발렌

발렌의 전선 전체를 보는 판단력은 신뢰하지만, 명령 전달이 늦으면 현장에서 먼저 움직인다. 발렌은 로크의 독단을 경계하면서도 그가 확보한 돌파구를 실제 전선으로 확장할 수 있다는 점을 높이 평가한다.

### 엘리아

엘리아가 제공하는 경로 분석과 적 공세 예측을 적극적으로 활용한다. 다만 분석이 길어지면 현장 관측 결과를 짧게 던지며 결론을 재촉한다. 엘리아에게 로크의 보고는 계획과 실제 전장의 차이를 확인하는 중요한 자료가 된다.

### 세딘

로크는 필요한 보급을 정확히 마련해 주는 세딘을 신뢰하지만, 장비를 거칠게 쓰는 습관 때문에 자주 지적받는다. 두 사람의 갈등은 목적보다 속도와 유지비를 어디까지 감수할 것인가에 있다.

## 말투 지침

- 짧은 평서문과 명령문을 사용한다.
- 상황 설명보다 결론과 행동을 먼저 말한다.
- 과장된 허세나 긴 영웅담은 피한다.
- 불확실한 상황에서도 머뭇거리는 표현을 남발하지 않는다.
- 대사에서는 `유닛`, `스위치`, `Location` 같은 편집기 용어를 사용하지 않는다.
- 전술 용어는 `전선`, `퇴로`, `사각`, `교란망`, `기동대`, `돌파구`처럼 현장 인물이 실제로 사용할 표현을 우선한다.

## 현재 구현된 대사

합류 대사:

```text
<1A>특수작전장교 로크: <04>교란망이 꺼졌군. 그 틈을 기다렸다. 이 전선은 지금부터 내가 맡겠다.
```

소유자 합류 안내:

```text
<07>[영웅 합류] <1A>로크<04>가 귀관의 지휘에 합류했습니다.
```

행동불능 안내:

```text
<06>[행동 불능] <1A>로크<04>가 후송되었습니다. 5분 후 미네랄 100을 소모해 배속된 지휘관의 본진에서 복귀합니다.
```

복귀 안내:

```text
<07>[전선 복귀] <1A>로크<04>가 배속된 지휘관의 본진에서 복귀했습니다. <1F>(미네랄 -100)
```

## 현재 게임 구현

- 영웅 시스템 초기화가 끝난 뒤 `AttackPoint1`의 전방 정신체 부재를 별도로 감지해 합류 요청을 기록한다.
- 이 감지는 난이도 선택 여부와 미션 진행 단계에 의존하지 않으므로, 난이도 선택 전에 정신체를 파괴해도 합류 요청이 보존된다.
- 로크 소유자는 Player 8의 `Zerg Nydus Canal` DC 하나로 기록한다. `0`은 미배속, `1~4`는 각각 P1~P4이며 별도의 배속 완료 스위치는 사용하지 않는다.
- 아직 영웅을 배속받지 않은 생존 플레이어를 우선해 무작위 배속된다.
- 합류 직전 `HeroCJoin`의 모든 플레이어/중립 `Men`과 `Buildings`를 `HeroCJoinExit`으로 이동시킨다.
- 정리된 `HeroCJoin`에 P9 일반 `Terran Vulture` 1기를 생성해 로크 배속 플레이어에게 이양한다. 이 벌처는 P9의 `Ion Thrusters` 연구 상태를 전달하기 위한 합류 선물이다.
- 이동과 같은 트리거에서 로크를 `HeroCJoin`에 생성한다.
- 생성 보호나 주변 적 제거는 적용하지 않는다.
- 행동불능 후 3600틱(5분)이 지나고 소유자가 미네랄 100과 본진 건물을 보유하면 복귀한다.
- HP, 공격력, 방어력, 업그레이드와 별도 고유 능력은 아직 변경하지 않는다.

## 향후 확장 시 유지할 핵심

- 로크의 정체성은 강한 화력 자체보다 기동, 판단 속도, 전장의 빈틈에 있다.
- 향후 능력을 추가하더라도 대규모 정면전 지휘관보다는 소수 정예 기동대와 어울려야 한다.
- 전방 정신체 아래에서 버틴 경험은 이후 교란, 고립, 퇴로 차단과 관련된 대사의 근거로 사용할 수 있다.
