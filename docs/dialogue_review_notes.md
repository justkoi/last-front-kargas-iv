# 카르가스 IV 대사 검토 노트

이 문서는 `KargasIV_Briefing.txt`와 `Triggers/*.txt`의 플레이어 표시 문구를 하나씩 같이 검토하기 위한 작업 노트입니다.

검토 기준:

- 대사가 캐릭터 목소리와 맞는가
- 플레이어가 다음 행동을 바로 이해할 수 있는가
- 브리핑 떡밥과 실제 미션 흐름이 맞물리는가
- 시스템/목표 문구와 인물 대사가 섞이지 않는가
- 색상 코드와 헤더가 과하지 않은가

## 전체 인상

현재 대사의 기본 골격은 좋습니다.

- 호크는 짧고 전술적인 현장 지휘관 톤이 살아 있습니다.
- 노바는 감지, 분석, 이상 징후 보고 역할이 분명합니다.
- `<03>` 호크, `<1A>` 노바, `<07>` 작전/보급 계열의 색상 구분도 읽기 좋습니다.
- 미션 1의 목표인 "첫 전선 구축"은 브리핑, 인게임 안내, 완료 문구까지 일관됩니다.

다만 같이 살펴볼 만한 지점은 크게 세 가지입니다.

- 브리핑에서 깔아둔 UED/프로토스 유적 떡밥과 현재 미션 2의 "잔존 군락 섬멸" 흐름 사이가 조금 벌어져 있습니다.
- 일부 목표 문구에 `P6/P7`, `미션2`처럼 에디터/제작자 관점의 표현이 남아 있습니다.
- 미션 1 후반부와 미션 2 안내에서 "군락", "전선", "방어선", "확보"가 반복되어 몇몇 대사는 기능문처럼 느껴질 수 있습니다.

## 우선순위

### 1. 브리핑 떡밥과 미션 2 방향 정렬

위치:

- `KargasIV_Briefing.txt`
- `Triggers/12_mission1_to_mission2_transition.txt`
- `Triggers/15_mission2_start.txt`

현재 느낌:

- 브리핑은 UED 통신 두절, 변종 생체신호, 프로토스 유적 반응을 주요 미스터리로 소개합니다.
- 하지만 현재 루트의 미션 2는 곧바로 갈색/하얀색 저그 군락 섬멸로 진행됩니다.
- 플레이어는 "UED 신호와 유적 이야기는 언제 이어지지?"라는 기대를 품을 수 있습니다.

검토 질문:

- UED/프로토스 유적 떡밥은 미션 3 이후로 넘기는 장기 떡밥인가?
- 아니면 미션 2에서도 약하게라도 다시 언급해야 하는가?
- 미션 2가 "잔존 군락 섬멸"이라면, 이 섬멸이 UED/유적 신호 추적으로 가기 위한 전초 작업임을 한 줄 더 분명히 할 필요가 있는가?

수정 방향 후보:

- 미션 2 시작부에 노바가 "북부 신호를 추적하려면 양쪽 군락의 생산망을 먼저 끊어야 한다"는 식으로 연결한다.
- 미션 1 완료 직후 호크가 "신호 확인은 뒤로 미룬다. 먼저 전선을 안정화한다"는 결정을 내려 흐름을 납득시킨다.
- 브리핑의 프로토스 유적 문장을 조금 더 "후속 떡밥"처럼 낮춘다.

예시 초안:

```text
<1A>노바: <04>북부 신호 추적 경로가 열렸지만, 갈색과 하얀색 군락이 양쪽에서 생산 반응을 올리고 있습니다.
<03>호크: <04>신호 추적은 전선이 버틴 뒤다. 먼저 양쪽 군락의 생산망을 끊는다.
```

### 2. 목표 문구의 제작자 용어 정리

위치:

- `Triggers/15_mission2_start.txt`

현재 문구:

```text
성공 조건: P6/P7의 해처리 / 레어 / 하이브 전멸
주의: 두 군락은 미션2부터 자원과 추적 공세를 재개
```

현재 느낌:

- `P6/P7`은 제작자나 에디터 기준 표현이라 플레이 중 몰입을 조금 깹니다.
- `미션2`는 다른 문구들과 맞춰 `미션 2`로 띄우는 편이 좋습니다.

수정 방향 후보:

```text
성공 조건: 갈색/하얀색 저그 진영의 해처리 / 레어 / 하이브 전멸
주의: 두 군락은 미션 2부터 자원 채취와 추적 공세를 재개
```

또는 더 세계관식으로:

```text
성공 조건: 갈색 군락과 하얀색 군락의 생산 구조 전멸
주의: 두 군락은 지금부터 자원 채취와 추적 공세를 재개
```

### 3. 미션 1 후반 대사의 반복감 완화

위치:

- `Triggers/09_mission1_waves_early.txt`
- `Triggers/10_mission1_waves_late.txt`

현재 흐름:

```text
호크: 가벼운 접촉에도 진형이 무너지면 끝이다. 방어선을 세워라.
호크: 압박이 올라간다. 첫 방어선이 버틸 수 있게 미리 보강해라.
호크: 놈들이 우리 방어선을 읽기 시작했다. 여기서 밀리면 첫 전선은 무너진다.
```

현재 느낌:

- 모두 역할은 분명하지만 "방어선/전선/버티기" 어휘가 반복됩니다.
- 일부는 웨이브 특징에 맞춘 구체적 명령으로 바꾸면 전투 리듬이 더 좋아질 수 있습니다.

수정 방향 후보:

```text
호크: 첫 접촉이다. 입구에서 받아내고 일꾼 쪽으로 흘리지 마라.
호크: 숫자가 늘었다. 수리선을 붙이고 화력을 한 지점에 모아라.
호크: 놈들이 반응을 바꿨다. 탐지와 대공을 비워두지 마라.
```

검토 질문:

- 호크를 더 차갑고 군인답게 갈 것인가?
- 아니면 현재처럼 플레이어를 직접 챙기는 지휘관 톤을 유지할 것인가?
- 각 웨이브의 실제 위협이 잘 드러나도록 대사를 더 전술화할 것인가?

### 4. 노바의 분석 톤 강화

위치:

- `Triggers/09_mission1_waves_early.txt`
- `Triggers/10_mission1_waves_late.txt`
- `Triggers/15_mission2_start.txt`

현재 느낌:

- 노바의 역할은 분명하지만, 몇몇 문장은 단순 경보에 가깝습니다.
- 노바는 "왜 이상한지"를 짧게 붙여주면 캐릭터성이 더 살아납니다.

좋은 현재 방향:

```text
노바: 군락 반응이 바뀌었습니다. 단일 무리가 아니라 조합을 돌리고 있어요.
노바: 두 군락 모두 아군 구조물 좌표를 추적하고 있습니다. 오래 두면 공세가 누적됩니다.
```

강화 후보:

```text
노바: 이동 간격이 일정합니다. 본능적인 공세가 아니라 명령 패턴에 가깝습니다.
노바: 두 군락의 생산 주기가 맞물립니다. 한쪽만 오래 두면 반격 간격이 더 짧아집니다.
```

검토 질문:

- 노바가 "변종이 지능적이다"는 느낌을 미션 1부터 더 강하게 드러내도 되는가?
- 아니면 미션 2 이후의 반전으로 남겨두는 편이 좋은가?

### 5. 보급/보상 문구의 톤

위치:

- `Triggers/12_mission1_to_mission2_transition.txt`
- `Triggers/17_mission2_resource_raids.txt`

현재 문구:

```text
군수지원: 북부 공세 대응 보급 투입. 미네랄 +800 / 가스 +200
군수지원: 외곽 생체 저장낭 회수 완료. 미네랄 +2000 / 가스 +800
```

현재 느낌:

- 보상 문구는 명확하고 좋습니다.
- 다만 "생체 저장낭 회수"가 실제로 자원 보상과 연결되는 설정은 조금 더 매력적으로 다듬을 여지가 있습니다.

수정 방향 후보:

```text
군수지원: 생체 저장낭 정제 완료. 전선 보급으로 전환합니다. 미네랄 +2000 / 가스 +800
```

또는 더 짧게:

```text
군수지원: 생체 저장낭 정제 완료. 미네랄 +2000 / 가스 +800
```

검토 질문:

- 보상 문구는 지금처럼 게임적으로 명확한 게 좋은가?
- 아니면 "회수/정제/보급 전환"처럼 세계관식으로 한 겹 덧입힐까?

### 6. 완료 문구의 엔딩감

위치:

- `Triggers/20_mission2_clear.txt`

현재 좋은 문구:

```text
호크: 방어선 재편을 시작한다. 카르가스 IV의 첫 전선은 버텼다.
```

현재 느낌:

- 엔딩감이 좋고, 미션 전체 제목인 "첫 전선"을 잘 회수합니다.
- 다만 작전 완료 직전의 문구들이 모두 안정화/완료/성공 계열이라 아주 약간 평평해질 수 있습니다.

수정 방향 후보:

```text
호크: 방어선 재편을 시작한다. 카르가스 IV에서 우리가 물러나지 않을 첫 선을 그었다.
```

또는 현재 톤 유지:

```text
호크: 방어선 재편을 시작한다. 카르가스 IV의 첫 전선은 버텼다.
```

권장:

- 현재 문구 유지 쪽이 더 간결하고 좋습니다.
- 손본다면 앞뒤 문구만 조금 줄이고, 이 문장을 마지막 감정선으로 남기는 편이 좋습니다.

## 파일별 체크리스트

- [ ] UED 통신 두절 떡밥의 비중이 적절한지 확인
- [ ] 프로토스 유적 반응이 너무 일찍 커 보이지 않는지 확인
- [ ] 호크의 첫 소개 직함이 너무 길지 않은지 확인
- [ ] 브리핑 목표와 인게임 목표의 표현을 맞출지 확인

### `Triggers/01_briefing_intro.txt`

- [ ] 브리핑과 인게임 첫 안내가 중복되어도 지루하지 않은지 확인
- [ ] 본진 진입로 표시 안내가 플레이어에게 충분히 명확한지 확인
- [ ] 호크/노바 첫 인게임 대사의 직함 표기 통일 확인

### `Triggers/09_mission1_waves_early.txt`

- [ ] 각 웨이브 대사가 실제 위협을 구체적으로 말하는지 확인
- [ ] "방어선" 반복을 줄일지 확인
- [ ] 탐지/잠복 경고가 플레이어 행동으로 바로 이어지는지 확인

### `Triggers/10_mission1_waves_late.txt`

- [ ] 후반 웨이브의 변종 조합감이 충분히 드러나는지 확인
- [ ] 주석 처리된 경보 문구를 유지할지 삭제할지 확인
- [ ] 호크의 "방어선을 읽기 시작했다" 문구를 살릴지 더 강하게 만들지 확인

### `Triggers/12_mission1_to_mission2_transition.txt`

- [ ] 미션 1 완료에서 미션 2 목표로 넘어가는 동기가 충분한지 확인
- [ ] 갈색/하얀색 군락을 색 이름으로 부르는 것이 괜찮은지 확인
- [ ] UED/유적 떡밥을 한 줄 연결할지 확인

### `Triggers/15_mission2_start.txt`

- [ ] `P6/P7` 표현을 플레이어용 표현으로 바꿀지 확인
- [ ] `미션2`를 `미션 2`로 통일할지 확인
- [ ] 미션 2 목표가 "잔존 군락 섬멸"로 충분히 매력적인지 확인

### `Triggers/17_mission2_resource_raids.txt`

- [ ] 생체 저장낭 보상 설정을 더 세계관식으로 다듬을지 확인
- [ ] 보상 문구가 전투 중 읽기 좋은 길이인지 확인

### `Triggers/18_mission2_new_pass.txt`

- [ ] 새 통로 안내가 선택 목표처럼 자연스럽게 들리는지 확인
- [ ] "탐색 가치" 표현을 더 전술적으로 바꿀지 확인

### `Triggers/19_mission2_airstrike.txt`

- [ ] 후방 공습 경고가 충분히 빠르고 명확한지 확인
- [ ] 현재 호크 대사는 유지 후보

### `Triggers/20_mission2_clear.txt`

- [ ] 완료 문구들의 순서를 더 감정적으로 정리할지 확인
- [ ] 마지막 호크 대사는 유지 후보
- [ ] 최종 Mission Objectives의 "이 전장은 끝났다" 톤이 적절한지 확인

## 같이 볼 순서 제안

1. `KargasIV_Briefing.txt`와 `Triggers/01_briefing_intro.txt`
2. 미션 1 웨이브 대사: `09`, `10`
3. 미션 1 완료와 미션 2 전환: `12`, `15`
4. 미션 2 선택/보상/후방 이벤트: `17`, `18`, `19`
5. 작전 완료 문구: `20`

첫 검토는 브리핑과 미션 2 전환을 먼저 보는 것이 좋습니다. 여기서 이야기 방향을 정하면 나머지 대사는 그 기준에 맞춰 더 쉽게 다듬을 수 있습니다.
