## Role

### 사령관 발렌 : 전술형
**작전사령관 발렌**은 병력을 함부로 소모하지 않으면서도, 기회가 오면 방어선을 행성 끝까지 밀어붙이는 현장 지휘관이다.

능력 : 주요 목표 달성시 유용한 보너스를 받습니다. (지역 점령, 파괴시 유용)



### 정보장교 엘리아 : 
**정보장교 엘리아**는 전장에서는 작은 신호 하나도 놓치지 않지만, 전투 밖에서는 의외로 빈틈을 보이는 분석가다.
능력 : 유용한 정보를 주기적으로 플레이어에게 제공합니다.

### 특수작전장교 로크 : 기동전형

**특수작전장교 로크**는 전방 정신체의 교란망이 무너지자 고립된 작전 구역에서 빠져나와 선봉대에 합류하는 기동전 지휘관이다.

상세 인물 문서: [특수작전장교 로크](인물_로크.md)

- 기반 유닛: Jim Raynor (Vulture)
- 합류 시점: 전방 정신체 파괴 후
- 현장 합류 위치: HeroCJoin
- 고유 능력: 아직 적용하지 않음

### 병참감찰관 세딘 : 중장갑 지원형

**병참감찰관 세딘**은 지휘 정신체의 방해 신호가 사라진 뒤 잔존 기갑대를 수습해 현장에서 합류하는 실무형 지휘관이다.

상세 인물 문서: [병참감찰관 세딘](인물_세딘.md)

- 기반 유닛: Alan Schezar (Goliath)
- 합류 시점: 지휘 정신체 파괴 후
- 현장 합류 위치: HeroDJoin
- 고유 능력: 아직 적용하지 않음
