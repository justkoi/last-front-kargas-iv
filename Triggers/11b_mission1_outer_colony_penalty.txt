//-----------------------------------------------------------------//
//  Mission 1 - outer colony attack penalty
//
//  If players bypass the first colony and attack P6/P7 during mission1,
//  destroyed outer-colony structures feed resources back into that colony.
//  If either outer colony's Hatchery/Lair/Hive collapses, both P6 and P7 wake up.
//  The first tech-core collapse immediately spawns one assault from the attacked
//  colony only (priming to the consume threshold). Each tech-core kill also
//  accelerates BOTH colonies' main-assault timers by 6480 (stronger than mission2
//  very hard's 5130 mirror), since the kill arms both colony timers (Switch33+34).
//-----------------------------------------------------------------//
