//  Opposite-colony-cleared variants - no main-assault acceleration.
//
//  Once one colony's MainBase tech core has collapsed (Switch31 = P6,
//  Switch32 = P7), destroying the surviving colony's Hatchery/Lair/Hive
//  no longer advances its main-assault cooldown - it only grants the
//  player resources and still counts toward the final-scream tally
//  (Zerg Sunken/Spore Colony, read by 18d). This cuts pointless attrition
//  so a winning team can finish faster. Reward/counter/consume are
//  difficulty-independent, so one trigger per building type is enough.
//  Mutually exclusive with the accelerating triggers above via the
//  opposite-colony switch (Set here vs Not Set above).
//-----------------------------------------------------------------//
