//  Switch142     : 군수시설 생존 게이트 — P9 BaseEntrance에 배럭 OR 팩토리 중 1개 이상 (1198~1200 스냅샷)
//  Switch145/146 : 무작위 선택자 1회 추첨(clear/clear=P1, set/clear=P2, clear/set=P3, set/set=P4)
//  Switch147     : 이양 완료(가드)
//  Switch151     : 개인 메시지 1회 출력 완료(가드)
//
//  이양 대상 결정(매 사이클 재추첨 없음 - 1200초에 1회만 추첨 후 우선순위 cascade):
//    1순위) 테란 보유 플레이어 우선 : P1->P4 순으로 첫 생존 테란에게.
//    2순위) 테란이 없으면 : 1회 추첨으로 뽑힌 생존 플레이어에게(무작위).
//    3순위) 뽑힌 플레이어가 비생존이면 : P1->P4 순 첫 생존 플레이어(안전망).
//    파일 순서(테란 cascade -> 추첨 -> 생존 scan)로 한 사이클 내 우선순위가 결정됨.
//  군수시설 생존 게이트 : 20:00 직전(1198~1200) P8이 배럭/팩토리를 각각 스캔해 Switch142 set.
//    이양 조건은 Switch142 Set만 확인. Give는 배럭·팩토리 둘 다 호출(있는 유닛만 이전).

//----- (A) 종족 감지 : 시작 3초, 일꾼으로 종족 판정 후 마커 DC 저장 (1회성) -----//
Trigger("Player 1", "Player 2", "Player 3", "Player 4"){
Conditions:
	Elapsed Time(At least, 3);                          //시작 3초 후 종족 스냅샷
	Elapsed Time(At most, 5);
	Command("Current Player", "Terran SCV", At least, 1); //테란 일꾼 보유 : 테란 종족
Actions:
	Set Deaths("Current Player", "Tom Kazansky (Wraith)", Set To, 1); //종족 마커 = 1(테란)
}

Trigger("Player 1", "Player 2", "Player 3", "Player 4"){

}

//----- (F) 이양 전체 공지 : P1~P4 소유로 보내 모든 플레이어가 보게 (각자 1회) -----//
//  P8 소유 트리거의 Display/Ping/WAV는 사람 플레이어에게 안 보이므로 분리한다.
//  가드 없이 비-Preserve로 각 P1~P4가 1회씩 발동(각자 화면에 표시).
//  개인 메시지(G)는 Switch151 체인으로 이양 다음 사이클에 1회 출력(AttackPoint1 B패턴).
Trigger("Player 1", "Player 2", "Player 3", "Player 4"){
Conditions:
	Switch("Switch147", Set);   //이양 완료 시 (각 플레이어 1회)
Actions:
	Minimap Ping("BaseEntrance");
	Play WAV("sound\\Misc\\TRescue.wav", 1500);
	Display Text Message(Always Display, "<03>호크: <04>입구 군수시설 복구를 마쳤다. 통제권은 한 지휘관에게 넘긴다.");
}
