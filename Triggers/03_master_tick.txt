// 최후의 공세 발사 이후 P6 Hunt 총공격 타이머를 영구히 3배속으로 진행한다.
// 아래 +2와 기본 타이머의 +1을 합쳐 720틱 임계치에 20초(240사이클)마다 도달한다.
// Switch84(기지 방어 중단)는 150 DC초 뒤 해제되지만 가속은 여기서 계속 유지된다.
Trigger("Player 8"){
Conditions:
	Deaths("Player 8", "Terran Valkyrie", Exactly, 3); //미션2 진행 중 : 미션 단계 DC가 정확히 3
	Switch("Switch75", Set); //P6 최후 공세 분기 : P7 붕괴 후 P6이 최후 공세 주체
	Deaths("Player 8", "Protoss Dark Archon", At least, 360); //최후 공세 발사 이후 : prep 타이머 30 DC초(발사) 경과부터 영구 (DA는 2161에서 멈추므로 항상 참 유지)
	Switch("Switch31", Not Set); //P6 미붕괴 : P6 본진 테크가 붕괴하면 가속 중단
Actions:
	Set Deaths("Player 8", "Terran Firebat", Add, 2);
	Preserve Trigger();
}

// 보상 굴림 wrap : 20 이상이면 20을 빼 0~19를 순환시킨다 (최대 19+7=26 → 1회 차감으로 0~6).
// stride가 1이 아니므로 Set To 0이 아니라 Subtract 20으로 오프셋을 보존한다.
Trigger("Player 8"){
Conditions:
	Deaths("Player 8", "Terran Comsat Station", At least, 20);
Actions:
	Set Deaths("Player 8", "Terran Comsat Station", Subtract, 20);
	Preserve Trigger();
}

// 스캔 페이즈 wrap : 4가 되면 0으로 되돌려 0~3을 순환시킨다.
// master_tick 증가 직후 + base_defense(파일14) 평가 이전에 위치해야
// 침입 트리거가 한 사이클에 안정된 페이즈 값을 본다.
Trigger("Player 8"){
Conditions:
	Deaths("Player 8", "Protoss Gateway", At least, 4);
Actions:
	Set Deaths("Player 8", "Protoss Gateway", Set To, 0);
	Preserve Trigger();
}
