//-----------------------------------------------------------------//
//  Mission 2 difficulty wave-size scaling
//
//  Balance note (assault scale rework):
//    Easy was cut -10% in the base wave files (10~13 / 20~23).
//    To keep Normal at the *original easy* +5% (= about -5% vs the old
//    Normal), the units removed from the base are moved back up into these layers:
//    half into the L2 (Normal, Academy At least 2) triggers and half into
//    the L3 (Hard, Academy At least 3) triggers, per unit type and wave.
//    Hard and Very Hard are then reduced by roughly 8% from the previous
//    totals while preserving each wave's unit mix as closely as integer
//    trigger spawns allow.
//
//  Net result per wave:
//    Easy      = base                  (-10% vs before)
//    Normal    = base + L2             (original easy +5%)
//    Hard      = base + L2 + L3 + reduced Hard+
//    Very Hard = Hard + adjusted L4
//
//  These triggers do not change orders, waypoint relay timing, rewards,
//  or Overlord support.
//
//  Hard+ reinforcement pass:
//    Hard and very hard receive a reduced shared wave-size layer after the
//    normal/hard/very-hard layers below. It is shared by both difficulties
//    with Terran Academy At least 3.
//-----------------------------------------------------------------//
